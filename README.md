# Open Ranking

An open, reproducible points system for the College Football Playoff, and **Open Ranking Models**, which forecast the selection committee's next ranking and the final field.

Status: pre-build. See `docs/PLAN.md` for the build plan and `docs/DECISIONS.md` for accepted decisions. Source proposals are in `docs/source/`; the v0 reference implementation is in `reference/v0/`.
